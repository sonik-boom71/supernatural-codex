# 🜏 Hunter's Codex — Кодекс Охотника

Тёмная мистическая фан-энциклопедия по сериалу **«Сверхъестественное» (Supernatural)**.
Архив Хранителей Знания: серии, персонажи, бестиарий, оружейная, интерактивная карта,
цитаты, саундтрек и интерактив — в атмосфере ночной дороги, Импалы и охотничьего дневника.

> *«Non timebo mala» — не убоюсь зла.*

## ✨ Возможности

- **Главная** — hero с Импалой на ночном шоссе, туман, частицы пепла, монстр и цитата дня
- **База серий** — все 15 сезонов, полный S1 и знаковые эпизоды; фильтры по сезону и событиям
- **Персонажи** — досье с фильтром по лагерю (охотники / ангелы / демоны / боги / люди)
- **Бестиарий** — монстры с уровнем угрозы, слабым местом и способом убийства
- **Оружейная** — Кольт, ангельские клинки, Первый Клинок, артефакты, ритуалы
- **Карта Винчестеров** — интерактивные метки локаций, включая Ад, Чистилище и Небеса
- **Цитаты** — генератор случайной цитаты + фильтр по персонажу + копирование
- **Саундтрек** — плейлист Импалы со встроенным YouTube-плеером, фильтр по сезонам
- **Интерактив** — тест «Кто ты из охотников?», квиз «Угадай серию», трекер просмотра, форма страшилок
- **Комьюнити** — прототип форума, фанфиков, фан-арта и рабочий опрос недели
- **Новости / Пасхалки / О проекте**
- **Режим «Ночная охота»** (кромешная тьма), кастомный скроллбар, пасхалки (7 кликов по логотипу)

## 🛠 Стек

| Слой | Технологии |
|------|-----------|
| Фреймворк | Next.js 14 (App Router), React 18, TypeScript (strict) |
| Стили | Tailwind CSS, CSS-переменные дизайн-токенов |
| Анимации | Framer Motion, CSS keyframes, SVG `feTurbulence` |
| Иконки | lucide-react + кастомные SVG (пентаграмма, дьявольская ловушка) |
| Данные | Статические TS-модули в `src/data` |
| Состояние пользователя | localStorage (трекер, опросы, истории, тема) |
| Опциональный бэкенд | Prisma + PostgreSQL (см. `prisma/schema.prisma`) |

Сайт полностью статический (SSG) и работает **без базы данных**.

## 🚀 Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшен-сборка
npm run start    # запуск собранной версии
```

Требуется Node.js 18.18+ (рекомендуется 20+).

## 📁 Структура

```
src/
├── app/                 # маршруты App Router (страницы + динамические [slug])
├── components/          # UI по разделам: hero, layout, episodes, characters,
│                        #   bestiary, armory, map, music, quotes, interactive,
│                        #   community, effects, icons, ui
├── data/                # контент: seasons, episodes, characters, bestiary,
│                        #   weapons, quotes, soundtrack, locations, news,
│                        #   easter-eggs, quiz
├── lib/                 # утилиты, маршруты, бейджи
├── providers/           # ThemeProvider (тема «Ночная охота»)
└── types/               # доменные типы
prisma/schema.prisma     # опциональная схема БД для бэкенда
```

## 🎨 Дизайн-система

- **Палитра:** void `#0a0a0a`, asphalt `#1a1a1a`, золото Импалы `#d4af37`,
  кровь `#8b0000`, огонь `#ff6b1a`, благодать ангелов `#4fa8ff`
- **Шрифты:** Bebas Neue (латинский логотип), Oswald (заголовки, кириллица),
  Playfair Display (декор/цитаты), Inter (текст), JetBrains Mono (акценты)
- **Эффекты:** туман, пепел, свечение карточек, мигание свечи, параллакс Импалы

Поддерживается `prefers-reduced-motion` — анимации отключаются.

## ☁️ Деплой на Vercel

1. Залейте репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → импортируйте репозиторий.
3. Framework определится как Next.js автоматически. Никаких переменных окружения для
   статической версии не требуется — жмите **Deploy**.
4. (Опционально) для бэкенда добавьте переменные из `.env.example`
   (`DATABASE_URL`, `NEXTAUTH_SECRET` и т.д.) и выполните миграции Prisma.
