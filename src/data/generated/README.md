# Сгенерированные данные TMDB

Файлы в этой папке заполняются скриптом `npm run tmdb` (см. `scripts/fetch-tmdb.mjs`).

- `tmdb-episodes.json` — все серии (после запуска скрипта — 327 эпизодов)
- `tmdb-people.json` — актёры с путями к фото
- `tmdb-show.json` — постеры шоу и сезонов

До первого запуска скрипта файлы пустые, и сайт показывает курируемый набор
серий из `src/data/episodes.ts`. После запуска с ключом TMDB здесь появятся
все 327 серий, рейтинги, кадры и постеры.

```bash
TMDB_API_KEY=твой_ключ npm run tmdb
```
